# Repository instructions

Start with the [documentation index](docs/index.md) and read the guides relevant
to your task. Read the coding style guide before changing code.

Use standard hyphens in place of em dashes and en dashes.

Follow Conventional Commits using the form `<type>: <summary>`. Use one of
these types: `fix`, `chore`, `feat`, `refactor`, `test`, or `ci`.
